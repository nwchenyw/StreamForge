# Privacy Policy for StreamForge

**Effective Date:** September 29, 2026  
**Project:** StreamForge ([https://github.com/nwchenyw/StreamForge](https://github.com/nwchenyw/StreamForge))

## 1. Zero Data Collection
StreamForge respects user privacy. The application **does not collect, harvest, store, or transmit any personally identifiable information (PII)**, usage data, or telemetry to any external server.

## 2. Local Processing
All media downloads, conversions, and configuration preferences (such as chosen language and download folders) are stored and processed strictly on the user's local device.

## 3. Network Communication
Network connections initiated by StreamForge occur solely for:
- Streaming or downloading media directly from user-provided URLs.
- Checking for software updates via public GitHub API endpoints.

## 4. Third-Party Services
StreamForge does not integrate third-party advertising networks, analytics tracking, or commercial tracking SDKs.

## 5. Contact
For any questions regarding this privacy policy or project security, please open an issue on the [StreamForge GitHub repository](https://github.com/nwchenyw/StreamForge/issues).
